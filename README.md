# GlitterGerda

A Dutch-language web app for creating animated glitter GIFs. Choose a caption, a theme and a glitter level, then preview and download the result.

Run `npm ci` and `npm run dev`, then open http://localhost:3000. The default demo mode works without credentials. For AI-generated backgrounds, set `OPENAI_API_KEY` in a local `.env.local` file. Configure your own deployment settings before hosting.
